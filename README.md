# Capability Lab 01 – Infrastructure Foundation

> Part of the Capability Labs series — demonstrating Infrastructure as Code (IaC) through modular, repeatable, and well-documented cloud infrastructure using Terraform.

---

## Overview

This repository is the first project in the **Capability Labs** series—a collection of focused engineering projects designed to develop and demonstrate practical skills in Platform Engineering, DevOps, Site Reliability Engineering (SRE), and Cloud Security.

This lab focuses on **Infrastructure as Code (IaC)** using Terraform and explores how cloud infrastructure can be provisioned consistently, reproducibly, and through version-controlled code rather than manual configuration.

---

## Engineering Problem

Modern cloud environments are often provisioned manually, resulting in inconsistent environments, configuration drift, and deployments that are difficult to reproduce.

Infrastructure as Code addresses these challenges by enabling infrastructure to be defined, versioned, reviewed, and deployed using code.

This project demonstrates that approach through Terraform.

---

## Engineering Capability

At the completion of this project, this repository demonstrates the ability to:

- Design cloud infrastructure using Infrastructure as Code
- Provision infrastructure using Terraform
- Build modular and reusable Terraform configurations
- Follow version-controlled infrastructure workflows
- Document engineering decisions and architecture
